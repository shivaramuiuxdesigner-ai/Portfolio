The Brief

Clinicians make life-affecting decisions under pressure. The dashboard had to match that gravity.

OnaWave needed a clinician-facing dashboard to visualise a patient's 28-day menstrual cycle dataset. Clinicians reviewing the data needed pattern recognition to be instant — not something they had to decode.

Badly designed medical dashboards don't just waste time — they create risk. The brief was to design a clear, dark-themed clinical UI that made every data point purposeful.

The Challenge

28 data points. 5 cycle phases. One screen.

The core tension: show enough data to be clinically useful without overwhelming the person reading it. I had to design a semantic phase color system, a readable chart layout, and an information hierarchy that let clinicians make a decision within seconds of loading the view.

The dark clinical theme wasn't an aesthetic choice — it was functional. Clinical monitors use dark backgrounds to reduce eye strain during long shifts and improve contrast for data visualisation.

Design Decisions

Color isn't decoration here. Every hue means something.

I built a 5-color semantic phase system — each cycle phase (Menstrual, Follicular, Ovulation, Luteal, Late Luteal) was assigned a distinct hue mapped to clinical convention. Not arbitrary. Not aesthetic.

Phase 01

Research & Data Audit

Mapped the 28-day dataset structure. Identified which data points were clinically significant vs. nice-to-have.

Phase 02

Semantic Color System

5-phase color mapping: Menstrual (red), Follicular (amber), Ovulation (green), Luteal (purple), Late Luteal (blue). WCAG AA compliant on dark backgrounds.

Phase 03

Dashboard Layout

Three-column layout: patient summary (left), primary 28-day chart (center), phase detail panel (right). Designed for 1440px clinical monitors.

Phase 04

Design Rationale Documentation

Full Notion-ready markdown rationale doc. Explains every color, spacing, and interaction decision with clinical justification.
