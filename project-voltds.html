The Brief

I kept building the same button in every project.

Every portfolio project I shipped had a slightly different component set. Different spacing. Different button radius. Different type styles. I was spending hours on decisions I'd already made before — just couldn't find them.

I wanted a system that made the right decision the default one. That's Volt DS.

The Challenge

One designer. No existing system.
No team to review it.

Most design system work happens in large teams with dedicated DS engineers. I had none of that. The constraint was building something rigorous enough to be genuinely useful without over-engineering it into something nobody could maintain — including me.

Architecture

Primitives first. Components only after
the foundation was solid.

The principle: if a component references a hardcoded hex value, it's not part of the system — it's just a Figma frame with a label on it.

Phase 01

Audit & Planning

Listed every visual property that repeated across projects. Found 40+ inconsistencies.

Phase 02

Primitive Color System

Full 22-color primitive palette, mapped to semantic aliases: background, text, border, action.

Phase 03

Typography System

1.25 modular scale. All Figma text styles created. Paired display and body typeface. Two platform tokens (Web & Mobile).

Phase 04

Spacing, Radius, Shadows

8pt base grid. 18 spacing tokens. 8 radius values. 4 elevation levels. All tokenised.

Phase 05

Component Library

26 components across 4 tiers: Primitives, Form Controls, Overlays, Navigation. 100+ total variants. Every component token-based.

Phase 06

80-Icon System

Based on Lucide icons. Normalised stroke weights, exported at 24px and 20px. Fully tokenised fill/stroke colours.

Phase 07

Documentation

16 LinkedIn posts. Component-by-component public documentation. Figma covers for each release. Available as a public Figma community resource.
